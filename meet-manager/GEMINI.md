# Gemini CLI Instructions

Read and follow [agents.md](./agents.md) before making any changes. It is the canonical project guidance.

Additional guidance for Gemini:

- Inspect the repository state and relevant source files before proposing edits.
- Follow the existing Next.js App Router, React 19, HeroUI v3, and Tailwind CSS v4 stack.
- Verify HeroUI v3 component names, slots, props, and event handlers against the installed version or its official documentation before using them.
- Preserve browser-only storage behavior and validate all imported backup data.
- Do not introduce backend-dependent features into this GitHub Pages static application.
- Run `npm run build` and state clearly whether it passed.
- Keep changes focused and do not overwrite the parent site's homepage.
